# Frontend: Framework

**Context**

Based on Typescript as the language of choice, it is beneficial to use a framework that offloads mundane tasks regarding UI interactivity and ease development, by using a web framework that fast-tracks development with features like reactivity. Because there are what feels like as many of these as there are stars in the universe, I only considered alternatives that I have hands-on experience with. The alternatives I considered are:

- Vue
- React
- Svelte
- HTMX
- Just use VanillaJS

**Decision**

I choose Vue simply because it is the framework I am most comfortable with it. It has a large ecosystem of plugins and extensions. The choice here is more subjective, but these frameworks are all very similar anyway so I’d argue it is more about preferance anyway.

**Consequences**

**Pros**

- Adds reactivity and interactivity
- Large community and ecosystem, containing libraries for state manage containing libraries for state management, routing etc.ment, routing etc.
- Integrates well with existing JavaScript libraries
- Familiar syntax for someone with experience in Vue.js
- Great documentation and learning resources
- Quick setup with Vite as build tool

**Cons**

- Slightly more complex build process
- Requires learning curve for those unfamiliar with Vue.js or reactive frameworks in general
- Adds an external dependency to the project, which comes with its usual downsides
